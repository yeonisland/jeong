# 근무 인수인계 웹앱

편의점 근무 교대 때 보내는 인수인계 글을 만들어 주는 모바일 웹 페이지예요. 설치 없이 `index.html` 하나로 동작해요.

## 열기
- 사이트: `https://yeonisland.github.io/portfolio/handover/`
- 파일을 내려받아 `index.html`을 브라우저로 열어도 돼요.

## 주요 기능
- **인수인계**: 동전·문화상품권 재고, 판매 내역(종량제·폐기물 스티커·담배·계좌이체·부분환불), 특이사항을 채우면 카톡용 글이 만들어져요. 오늘 할 일, 지금 근무 남은 시간, 전달 사항(고정), 지난 근무와 재고 비교도 있어요.
- **달력**: 날짜별 기록 저장, 근무 변경, 시급 기준 월 급여 계산, 월말 근무시간 보고, 저온 물류 도착 평균, 백업·복원.
- **매뉴얼**: 자주 쓰는 업무 방법을 적어 두는 곳.
- **소비기한**: 상품·소비기한·입고일을 기록하고 기한 순으로 확인, 확인 시간 알림.
- **설정**: 정기 근무 요일·시간, 항목 켜고 끄기, 봉투·스티커 규격 수정, 직접 만드는 항목.
- **사진**: 진열 사진을 줄여서 저장하고 공유.

## 저장 방식
- 로그인 없이 쓰는 브라우저에만 저장돼요 (localStorage, 사진은 IndexedDB). 기기나 브라우저를 바꾸면 비어 있어요.
- 달력 탭 맨 아래 "기록·설정 백업"에서 복사해 두었다가 복원할 수 있어요. 사진은 백업에 들어가지 않아요.
- 이름과 근무번호는 기본값이 비어 있고, 월말 보고 칸에서 직접 적어요.

## 만든 방식
HTML, CSS, JavaScript만 사용했고 외부 라이브러리는 없어요. 글꼴만 Google Fonts에서 불러와요.
